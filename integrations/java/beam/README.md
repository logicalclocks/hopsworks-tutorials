# Apache Beam

The Apache Beam example was removed together with the `hsfs-beam` library, which Hopsworks no longer ships after 5.2.

For Hopsworks 5.2 and earlier, the example is still available at [this commit](https://github.com/logicalclocks/hopsworks-tutorials/tree/27d1cd82635823634a12a296e4772b7bf9d79096/integrations/java/beam).
